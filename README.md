# ÍMPAR TECHNOLOGY — site institucional

Site institucional estático em HTML/CSS/JavaScript. Arquivos destinados exclusivamente à publicação no GitHub Pages.

## Proteção dos projetos
Este repositório não deve conter arquivos `.apk`, `.aab`, `.env`, tokens, repositórios de aplicativos, dumps de banco de dados ou códigos internos dos projetos. Todos os conteúdos commitados aqui serão públicos.

## Publicação (somente após revisão)
No GitHub, em Settings → Pages, selecione `Deploy from a branch`, branch `main`, pasta `/(root)` e salve. O endereço previsto é `https://giovani-play.github.io/impar-technology-site/`.

## Conteúdo
Todas as imagens da galeria estão explicitamente descritas como ilustrativas. Nenhum produto próprio é anunciado como lançado.

## Licenças de imagens
Imagens fornecidas pelo titular do projeto para uso institucional. Confirmar autorizações de uso público e direitos de imagem das pessoas retratadas antes de ativar o site.
