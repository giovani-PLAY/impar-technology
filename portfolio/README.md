## Segurança e publicação

- Não adicionar APK, AAB, arquivos .env, chaves de API, credenciais, banco de dados, código privado, gravações de clientes ou documentos internos.
- Não usar capturas conceituais como se fossem prints funcionais.
- Não afirmar publicação ou comercialização sem comprovação.
- Mantenha este portfólio separado das fontes dos aplicativos.
- Revise o texto da página pública antes de fazer merge.
- O site pessoal fica dentro do repositório institucional por economia; se necessário, pode ser migrado depois para um repositório independente, sem mudanças de conteúdo.
